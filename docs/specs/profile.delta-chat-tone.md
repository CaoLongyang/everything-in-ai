# Delta Spec: profile V2（聊聊不要尬聊）

Status: 已批准 2026-11-27（作者试聊后：「有点尬聊的感觉了」）　版本：V2
改动对象：`docs/specs/profile.delta-chat.md` 第 2、4 节

## 试聊发现的问题（2026-11-27 作者第一次聊）

| 现象 | 例子 |
|---|---|
| 开场装熟、复述画像 | 「我是你的新朋友～听说你从浙江一路读到马来西亚」 |
| 像人口普查 | 「家里现在还有谁常住？」「你爸妈平时是做什么工作的？」 |
| 一次问两个问题 | 回应里问「一天大概是怎么过的？」，下面又问「有没有固定的小习惯？」 |
| 替你脑补感受、居高临下 | 「他们也会常惦记你吧」「一个人还能自己开火，挺不容易」 |
| 调侃 | 「打游戏和玩手机倒像是大家的标配了哈哈」 |
| 你答得短、跳过了还在追细节 | 你答「打游戏 做饭 玩手机」，它追问做什么菜 |

## 改动

1. **提示词**：开场只是一句简单的招呼，不自称「新朋友」，不说「听说你……」；第一个问题从画像里你明显喜欢的轻松话题开始，不从家庭的事实问起。回应只针对你实际说的内容，不猜感受、不居高临下地夸、不调侃、不用「哈哈」「～」。多请你讲一件具体的事，少问人口普查式的事实。
2. **一次只问一个问题**（程序）：回应里以问号结尾的句子删掉，问题只留在「问题」那一栏。开场的招呼除外。
3. **看你的反应**（程序）：最近两题都答得很短（8 个字以内）或者跳过了，告诉 AI 别再追这个话题的细节，换到你画像里明显感兴趣的话题，或者给你两个话题选。
