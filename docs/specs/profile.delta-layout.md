# Delta Spec: profile V2（排版）

Status: 已批准 2026-11-26（作者读第二份画像后要求「格式好看一些，不然很乱」）　版本：V2
改动对象：`docs/specs/profile.delta-format.md`（已批准）第 1 节的每小节写法

内容和章节结构不变，只改排版：正文只留内容，把证据、把握、反馈标记挪开。

| 原来 | 现在 |
|---|---|
| 文件开头三行提醒，再是 `# 你：标签…` | `# 个人画像`、提醒、`**一句话的你：** 标签…`、**目录**（每章列出有内容的小节） |
| `### 动机模式　`缺启动锚点``，下一行是说明 | `### 动机模式`，下一行引用块 `> **缺启动锚点** —— 说明` |
| `- [ ] 不像我｜要点（把握：高｜5 个对话、5 天）` + 折叠的证据块 | `- [ ] 要点[^12]`；勾上方框就是「不像我」 |
| 证据在每条下面 | 证据是脚注，集中在文末 `## 证据`：`[^12]: 把握高 · 5 个对话、5 天：「原话」—— [[对话]]；……`，最多 8 条 |
| 决策、时间线：`不像我｜2026-10-02｜要点` | `- [ ] **2026-10-02** 要点[^n]` |
| 章与章之间无分隔 | 每章前加 `---` |

- 「不像我」：三种写法（第一版、第二版、现在）勾上的都认。
- 验收：F18-09 的「证据在折叠块里」改为「证据是文末脚注」，F18-12 的「新旧格式」改为三种格式，其余不变。
