# Delta Spec: chat-sync（插件单独开源、不装 eia 也能用）

Status: 已批准 2026-11-27（作者：插件单独开源；「能独立用」；新仓库和主仓库「两边都留」）　版本：V2
改动对象：`docs/specs/chat-sync.md` 第 4.1 节（插件只发给 eia）

## 改动

1. **两种存法**，在插件设置里选：
   - **存成文件**（没装 eia 的人用）：每个对话一个文件，放进浏览器「下载」文件夹的 `ai-chat-sync/<平台>/`。可选 Markdown（默认）和网站返回的原始 JSON。同名覆盖；同步期间不弹下载提示。
   - **发给 eia**：和原来一样。
   - 没选过时：填了口令的当作「发给 eia」（已经在用的人不受影响），否则是「存成文件」。
2. **转换**：存成文件时，插件自己把三家的原始对话转成统一结构，规则和 eia 的导入一致（ChatGPT 走 `current_node` 那一支、只要文字、图片留占位；Claude 走当前分支、只要 `text` 块、附件留占位；Gemini 按时间排、只取选中的回答）。认不出的格式记「格式认不出」，不写文件。
3. **增量**：存成文件时没有 vault 可比，插件自己记下每个对话存过时的更新时间和文件名（插件存储里，不含内容）。下次只存更新过的；对话改了标题也写回原来那个文件。
4. **同一个接口**：「存成文件」在插件里模拟 eia 的 `/status`、`/plan`、`/conversation` 三个接口，同步流程、限速、出错处理完全不变。
5. **单独的仓库** `CaoLongyang/ai-chat-sync`（MIT）：内容是本仓库 `extension/` 的拷贝，加上英文说明、eia 接口说明（`PROTOCOL.md`，别人可以照着写自己的接收端）、第三方声明。**本仓库的 `extension/` 是源头**，改了之后再同步过去。

6. **中英文**（2026-11-27 作者：单独的插件要有英文的输出）：设置里选语言，默认跟随浏览器（中文浏览器用中文，其他用英文）。影响弹窗、同步提示、存下来的 Markdown 里的说话人（「我」/ You）和占位文字（图片、附件、未命名对话）。文件名、文件夹名和 frontmatter 的字段名不随语言变；已经存过的文件，下次更新时才换成新语言。插件在 Chrome 扩展列表里的名字也有中英文（`_locales/`）。

已知局限：存成文件时，如果用户手动删了某个文件，插件不知道，对话没更新就不会再存；要全部重存，在插件设置里「清空记录」（以后做）或重装插件。
