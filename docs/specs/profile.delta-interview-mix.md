# Delta Spec: profile V2（访谈默认浅深搭配）

Status: 已批准 2026-11-27（作者：「默认应该是轻松居多，然后中等，再加入一两个深度题目」）　版本：V2
改动对象：`docs/specs/profile.delta-interview-depth.md` 第 1 条（深度三选一、按最浅的出题）

## 改动

1. 「深度」从「最多问多深」改成「一轮里浅的、中等的、深的各几个」。三个选项：

   | 选项 | 一轮里（最多 8 题） |
   |---|---|
   | **轻松为主，加几个深一点的**（默认） | 大部分轻松；中等最多 3 个；深的 1–2 个（最多 2 个） |
   | 只问轻松的 | 全部轻松 |
   | 多问深的 | 中等最多 3 个，深的最多 4 个，其余轻松 |

   勾了几个按最浅的（只问轻松的 → 默认 → 多问深的）。

2. AI 给每题标深浅（`depth`：light / medium / deep）。程序：
   - 超过数量的中等、深的题删掉（AI 标错深浅程序看不出来，靠提示词）。
   - **按从浅到深排**：轻松的在前（热身），深的在最后；同样深浅里追问在前，然后是你勾了的方面。
   - 中等、深的题，程序在「为什么问」后面加「想到多少说多少，没想好也可以。」，访谈文件里标「（深一点）」。
3. 语气规则、「还没想好」不变。
