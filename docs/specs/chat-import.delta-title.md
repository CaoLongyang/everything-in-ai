# Delta Spec: chat-import（标题只留一行）

Status: 已批准 2026-11-26（作者让 AI 助手处理「Gemini 对话的标题是一整段代码」这件小事）　版本：V2
改动对象：`docs/specs/chat-import.md` 第 4 节字段表的 `title`；`docs/specs/chat-import.delta-gemini.md` 的 `title` 行

## 为什么改

Gemini 浏览器插件导出时，有的对话没有标题，就把整条第一句话当标题。作者的 test-vault 里有 5 个这样的对话，最长的标题 4,066 字（一句「帮我写注释」加上整段 Java 代码），在 Obsidian、试用台和画像的证据链接里都很难看。

## 改动

- 导入时（新建和重新导入都一样），`title` 只取**第一个非空行**，连续空白合成一个空格；超过 **80 字**的截到 80 字，末尾加「…」。
- 文件名用处理后的标题。
- 对所有平台都生效。ChatGPT、Claude 的标题本来就是短的一行，不受影响。
- 处理后为空的，照旧写「未命名对话」。

## 已有文件

重新导入时，只有对话有了新消息（`updated` 变了）才会改 frontmatter，所以已有的 5 个文件要等那 5 个对话下次有新消息、再导入时才会变短。也可以在 Obsidian 里手动改标题，重新导入不会覆盖成长的，因为新标题本来就是截过的。
