# Delta Spec: profile V2（观察太多时按时间均匀挑）

Status: 已批准 2026-11-26（作者同意先修这个再跑全部对话）　版本：V2
改动对象：`docs/specs/profile.delta-format.md` 第 3 节「观察总量超过一次能发的上限时，保留最近的」

## 为什么改

只跑最近 3 个月时，观察总量（约 4 万字）远低于一次汇总的上限（6 万字）。全部对话（1,407 个，约 219 万字）会多出好几倍；照原来「只保留最近的」，画像实际上只根据最后几个月写，前几年分析了却用不上。

## 改动

- 一次汇总的上限从 6 万字提到 **12 万字**（约 8 万 token，DeepSeek 一次能收下）。
- 超过上限时**按月轮流挑**：每一轮从每个月各挑一条（月内先挑最新的），直到装满。每个时期都有份，观察多的月份也不会把别的月份挤掉。
- 你主动补充的（访谈回答、「我的补充」）**一律先放进去**。
- 画像开头的说明改成「观察太多，按时间均匀挑了一部分，有 N 条没有参与汇总」。

已知局限：观察特别多时，每个月只有一部分能进汇总。真要全部用上，以后可以改成「先按年汇总、再汇总成一份」，那是另一个改动。
