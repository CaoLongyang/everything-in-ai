# Delta Spec: profile V2（访谈的深度和语气）

Status: 已批准 2026-11-27（作者同意第 1–3 条；第 4 条「敏感话题默认不问」不做：「用户不想聊就不聊」）　版本：V2
改动对象：`docs/specs/profile.delta-interview.md`

## 为什么改

作者答完第二轮：「这些问题也太扎心了，甚至有些是我自己都没有想好的问题，我不知道其他用户看到会怎么样。」

原因：提示词只要求「找空白、往深里问」，没规定怎么问。AI 会把两件事拼在一起对质（「你信改革宗，又会为砍价几百马币反复纠结……」）、先下结论再问（「你对自己行动力的问题……」）、一上来就问还没想清楚的事。第一次用的人会觉得被审问。

## 改动

1. **深度**，在「访谈设置」里选，默认「轻松」：

   | 深度 | 问什么 | 例子 |
   |---|---|---|
   | 轻松（默认） | 事实和经历 | 「你在哪长大？」「最近在忙什么？」「做过最有意思的项目是什么？」 |
   | 适中 | 原因和感受 | 「为什么选这个专业？」「那段时间对你来说是什么感觉？」 |
   | 深入 | 困惑、矛盾、还没想清楚的事 | 「你现在对将来最拿不准的是什么？」 |

   勾了几个就按最浅的那个。已有的「访谈设置」里没有这一节时，程序在文件末尾追加一次（和「（自动）」行一样，只追加、不改你写的）。

2. **语气**（所有深度都适用，写进提示词）：
   - 不把两件事拼在一起对质，不用「你……又……」「为什么你总是……」这种句式。
   - 不先下结论再问（不说「你的某某问题」），用好奇的口气问经历，不用诊断的口气。
   - 适中、深入的问题，「为什么问」后面加一句「想到多少说多少，没想好也可以」。

3. **「还没想好」也算回答**：回答只写了「还没想好」「没想好」「不知道」「没想清楚」「说不清」这类（20 字以内）：
   - 不算跳过，不会因此把这个方面加进「不想聊」。
   - 不拿来追问。
   - 30 天之后可以再问（换个问法），之前不问。

4. ~~敏感话题默认放进「不想聊」~~：不做。哪些不想聊由用户自己写。
