# Delta Spec: profile V2（访谈个性化）

Status: 已批准 2026-11-27（第 6 节四项都按推荐）　版本：V2
改动对象：`docs/specs/profile.delta-v2b.md` 第 1 节（访谈 `eia profile ask`）

## 0. 要解决的问题

作者 2026-11-26：「这个访谈不同数据的输入会导致很多不同的问题吧，所以其他用户使用的时候访谈应该是更加个人化的东西。」

现在的访谈：

| 现象 | 后果 |
|---|---|
| 每次只看画像出 10 个问题，不看以前问过什么、你答了什么 | 答过的事不会往深里问；可能重复问 |
| 你没法说「这个我想聊」「这个别问」 | 只能被动答，不想谈的事每次都可能被问到 |
| 空着不答的题没有任何作用 | 你明显不想谈的话题，下次还会问 |
| 提示词里的例子是「你是怎么开始信基督教的？」「为什么选择来马来西亚读书？」 | 这是按作者写的；别人的画像会被带偏，问出不相干的问题 |
| 问题全靠 AI 看画像哪里空着 | 画像里从来没出现过的人生领域（比如童年），AI 不知道该问 |

## 1. 访谈设置：你来定主题和禁区

第一次运行 `eia profile ask` 时，建一个 `profile/访谈设置.md`（`note` 类型）。之后程序**只读、不改**，除了第 3 节自动加的「不想聊」行（加在文件末尾，带「（自动）」标记，你可以删）。

```markdown
## 想聊的方面
勾上的会优先问；全不勾 = 都可以问。

- [ ] 成长与家庭：在哪长大、家里的人、小时候的事
- [ ] 求学：为什么选这个学校、这个专业，读书时的转折
- [ ] 工作与项目：做过什么、为什么做、做成了什么
- [ ] 价值观与信仰：在意什么、相信什么、这些是怎么来的
- [ ] 人际关系：重要的人、朋友、怎么相处
- [ ] 转折点：改变了你的几件事
- [ ] 现在和将来：最近在忙什么、想成为什么样的人

## 也想聊（自己写，一行一个）

## 不想聊（一行一个；这些话题不会被问到）

```

- 这七个方面就是第 4 节「人生故事框架」的七章。
- 「不想聊」里写的词：AI 被要求不问；程序再检查一遍，问题或「为什么问」里出现这些词的直接删掉（第 7 节 F18-22）。
- 只预览（不加 `--yes`）时不建这个文件，什么都不写。

## 2. 追问：接着你上次的回答往下问

再次运行 `eia profile ask` 时，除了画像结论，还发出**以前所有访谈里你写了回答的问答**（问题 + 你的回答）。AI 做两件事：

- **追问**：从你的回答里挑出值得往下问的（提到了一件事但没展开、提到一个人、一个转折），每次最多 3 个追问。追问标「（追问第 N 轮第 M 题）」，让你知道接的是哪一句。
- **不重复**：已经问过的（不管答没答），换个问法也不再问；程序按问题文字去重，几乎一样的也删掉（F18-23）。

发出前照常先告诉你发多少字、发给谁（和现在一样要 `--yes`）。回答是你自己写的话，和第 2 步分析对话发出的内容同一类，README 隐私表那一行加上「以前的访谈回答」。

## 3. 跳过也是信号

- 每个问题都标一个方面（第 1 节的七个之一）。
- 你空着没答的题，不再问。
- 同一个方面，连续两轮的问题你**全部**空着 → 程序在「访谈设置」的「不想聊」末尾加一行 `- （自动）成长与家庭`，以后不再问这个方面。你删掉这一行就恢复。
- 实现：那一行下面另起一行留一个看不见的记号 `<!-- eia:auto family -->`（Obsidian 阅读模式里不显示）。你删掉「（自动）」那行、记号还在，程序就知道这是你自己恢复的，不会下一轮又加回去。
- 只空一部分不算：可能只是那题不想答，或者没时间。

## 4. 人生故事框架

心理学里常用的「人生故事访谈」（Life Story Interview，McAdams）把一个人的故事分成几章来问。这里简化成第 1 节的七个方面，用来补 AI 看画像发现不了的空白：

- 程序先数每个方面**已经有多少条你的回答**，加上画像对应章节有几条要点（比如「求学」对应「02 学业与职业」的教育小节），一起发给 AI。
- 每轮的问题：先放追问（最多 3 个），剩下的名额优先给**你勾了的方面**里最薄的，再给其他没被「不想聊」排除的方面里最薄的。
- 每轮一共最多 8 个问题（原来是 10 个；有了追问，一轮少一点更容易答完）。

## 5. 提示词去掉作者本人的例子

`ASK_SYSTEM` 里的例子换成和具体某个人无关的写法，例如「你是怎么决定现在读的专业的？」「有没有哪件事让你对某个看法改变了主意？」「小时候对你影响最大的人是谁？」。别的提示词里按作者情况写的例子（找室友、签证）也一起检查，换成中性的。

## 6. 待你决定

1. **设置放在哪里**（推荐 a）
   - a. `profile/访谈设置.md`，在 Obsidian 里勾选、写字，和「我的补充」一样。
   - b. `config.yaml` 里加一段 `profile.interview`：更「程序化」，但要改 YAML，新人不友好。
2. **自动加「不想聊」**（推荐 a）
   - a. 连续两轮一个方面全空 → 自动加，带「（自动）」标记，可以删。
   - b. 不自动加，只在命令输出里提示「你好像不想聊某某，要不要加进不想聊」。
3. **每轮几个问题**：最多 8 个，其中追问最多 3 个。（推荐）
4. **七个方面**：按第 1 节的七个。要增删的话现在说。（推荐照用）
