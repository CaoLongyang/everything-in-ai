# ADR 0005：定时运行实现中的决定

日期：2026-11-21　状态：已采纳
相关：`docs/specs/scheduler.md`

1. **用 `pythonw.exe -m eia run ...`**，不用 `eia.exe`：后者是控制台程序，每次运行都会闪出黑色窗口。为此加了 `src/eia/__main__.py`。
   pythonw 下没有 stdout，click 的 echo 会直接跳过，结果都写进运行记录。
2. **读回 vault 路径用「起始于」列，不用命令列。** 2026-11-21 在作者电脑上实测：`schtasks /Query /FO CSV /V` 会把命令里的引号弄乱
   （显示成 `--vault C:\...""`）。登记时把工作目录设成 vault，读「起始于」最可靠；命令列的正则只作后备。测试用的是实测的真实格式。
3. 表头随系统语言变，按**列位置**读（1 任务名、2 下次运行、3 状态、5 上次运行、6 上次结果、8 命令、9 起始于）。输出编码随控制台变，先试 UTF-8 再退回系统编码。
4. 任务名 = `\eia\<job>-<vault 绝对路径小写后 sha256 前 8 位>`：同一台电脑多个 vault 互不干扰，重复登记就是覆盖（`/F`）。
5. `eia run` 把任务里的一切异常都记成失败（`except Exception`），因为定时运行时没人看终端；锁超过 2 小时视为上次被强制结束的残留。
6. 手动验收（2026-11-21，作者电脑，真实 vault）：登记成功，`schtasks /Run` 触发一次，退出码 0、运行记录写入，`list` / `status` 显示正确。
