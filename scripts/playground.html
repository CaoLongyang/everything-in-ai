eia 试用台只在你的电脑上运行

这个 vault

知识库就是一个文件夹。这里显示它的配置和内容数量。

格式检查 eia validate

逐个检查 Markdown 文件的字段是否合规。只读，不改文件。

新建一个空 vault eia init

在填写的路径创建目录结构和带注释的配置模板。已有文件不会被改动。

加载中……
从左边选一个文件。这里显示的和 Obsidian 里看到的是同一个文件：上面是属性（frontmatter），下面是正文。只读。
加载中……
从左边选一个对话，这里会像聊天软件一样显示你和 AI 的每一条消息。

统计 eia chats stats

每个平台有多少对话、你说了多少话。

在所有对话里搜我说过的话 eia chats dump

勾上“只看我说的”，AI 的回答和思考过程一句都不会出现。笔记是你在对话文件里自己写的内容。

导入对话 eia import

读官方导出的 zip，不用解压。先用“预览”看会新建多少，再真的导入。重复导入只更新，不会重复，你加的标签和笔记会保留。

运行雷达 eia headlines run

抓取配置里的新闻源 → 用向量模型把讲同一件事的报道归组 → 至少几家独立媒体都在报的写成条目。需要 Ollama 开着。

每天自动运行 eia schedule

登记到 Windows 任务计划程序。电脑那时关着，开机后补跑；不会弹出窗口；不需要管理员权限。每次运行的结果都记在下面。

已有的大事

按报道的媒体数排序。数字是独立媒体数，同一家媒体的中英文源只算一家。

今日兴趣 eia digest

用你的兴趣清单给新闻雷达抓到的报道打分（本机计算，不花钱）。评价会马上影响之后的挑选：标了不相关的，和它很像的报道以后不再出现。

我的兴趣清单

勾上的就是你的兴趣。可以直接改名字、说明，「不要」里写不想看的方向。下面的草稿（从对话生成的、根据评价改进的）也在这里，确认后才生效。

从对话生成兴趣草稿 eia interests draft

第 1 步在本机把你说过的话按主题归组，不发出任何内容（第一次约 3 分钟）。第 2 步每组挑几段摘录发给你配置的 AI 起名字，发之前会告诉你发多少字。

根据评价改进兴趣 eia interests learn

把兴趣清单和你的评价（报道标题、你写的理由）发给 AI，让它提出修改建议。建议会出现在上面的清单里，你确认后才生效。

新闻雷达的 AI 过滤

雷达用“向量模型”判断两篇报道讲的是不是同一件事。推荐本地 Ollama 的 bge-m3：不花钱、新闻不出电脑、中英文都能比。

新闻源

勾上的才会抓。同一个媒体名的多个源只算一家。推荐源都在 2026-11 实测可用。
